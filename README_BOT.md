# Медицинский Ассистент - Руководство по использованию

## Описание

Медицинский ассистент - это интеллектуальный бот, который помогает пациентам получить первичную медицинскую консультацию. Бот автоматически проводит опрос и предоставляет рекомендации на основе симптомов.

## Как работает бот

### 1. Приветствие и опрос
При создании нового чата бот автоматически:
- Приветствует пользователя
- Задает 3 обязательных вопроса:
  1. **Сколько вам лет?** - для определения возрастной группы
  2. **Укажите пол?** - для учета гендерных особенностей
  3. **Что вас беспокоит?** - для анализа симптомов

### 2. Обработка ответов
- **Возраст**: Бот извлекает число из ответа (например, "25" из "мне 25 лет")
- **Пол**: Принимает различные варианты ответов (мужской/женский, м/ж, male/female)
- **Симптомы**: Сохраняет полное описание проблемы

### 3. Медицинский анализ
После завершения опроса бот:
- Анализирует симптомы с учетом возраста и пола
- Предоставляет возможные причины
- Дает рекомендации по самопомощи
- Указывает, когда необходимо обратиться к врачу
- Предлагает меры профилактики

## Технические особенности

### Модели данных
```python
class ChatSession(models.Model):
    # Поля для опроса
    is_survey_completed = models.BooleanField(default=False)
    patient_age = models.IntegerField(blank=True, null=True)
    patient_gender = models.CharField(max_length=10, blank=True, null=True)
    patient_symptoms = models.TextField(blank=True, null=True)
    survey_step = models.IntegerField(default=0)
```

### API интеграция
- Использует DeepSeek API для генерации медицинских рекомендаций
- Форматирует ответы в HTML для лучшего отображения
- Обрабатывает ошибки API с fallback-ответами

### Безопасность
- Все данные сохраняются в базе данных
- Предупреждения о необходимости консультации с врачом
- Ограничения на возраст (1-120 лет)

## Использование

### Для пользователей
1. Зайдите в раздел "Чат"
2. Нажмите "Новый чат"
3. Ответьте на вопросы бота
4. Получите медицинские рекомендации

### Для разработчиков
```python
# Создание новой сессии
session = ChatSession.objects.create(
    user=user,
    is_survey_completed=False,
    survey_step=0
)

# Обработка ответа пользователя
result = handle_survey(session, user_response)

# Создание медицинского резюме
summary = create_medical_summary(session)
```

## Важные замечания

⚠️ **Важно**: Бот предоставляет только общие рекомендации и не заменяет консультацию врача. При серьезных симптомах обязательно обратитесь к специалисту.

### Ограничения
- Бот не ставит диагнозы
- Не назначает лекарства
- Не заменяет экстренную медицинскую помощь

### Рекомендации по улучшению
1. Добавить больше валидации ответов
2. Расширить базу знаний симптомов
3. Интегрировать с медицинскими справочниками
4. Добавить поддержку изображений
5. Реализовать многоязычность
